shipcheck turns the test run your agent already did into the GitHub check its PR waits for. It runs your workflows locally with act, keeps the result for each git tree, and posts the required `shipcheck` check.

New here? [Install it](@/docs/install.md), then follow the [quickstart](@/docs/quickstart.md). It takes a few minutes for a repository owner and one command for each teammate. Once it works, [speed up runs](@/docs/speed.md).

Using a coding agent? [Agents](@/docs/agents.md) says what `init` and `install` set up for Claude Code, Codex, Cursor, Gemini CLI and Copilot CLI.
