shipcheck turns the test run your agent already did into the GitHub check its PR waits for. It runs your checks locally, natively in an OS sandbox or as your workflows in containers with act, keeps the result for each git tree, and posts one required check per job, such as `shipcheck/test`.

New here? [Install it](@/docs/install.md), then follow the [quickstart](@/docs/quickstart.md). It takes a few minutes for a repository owner and one command for each teammate. Once it works, [speed up runs](@/docs/speed.md).

Using a coding agent? [Agents](@/docs/agents.md) says what `init` writes for it, with any agent.

Deciding whether to trust it? [What a green check proves](@/docs/proof.md) and [Security](@/docs/security.md) say what a check guarantees and what a job can reach.
